Citing py-sc-fermi
==================

If you use py-sc-fermi in published work, please cite the JOSS paper:

    A. G. Squires, D. O. Scanlon and B. J. Morgan, *py-sc-fermi: self-consistent
    Fermi energies and defect concentrations from electronic structure
    calculations*, Journal of Open Source Software, 8(82), 4962 (2023).
    `doi:10.21105/joss.04962 <https://doi.org/10.21105/joss.04962>`_

The software itself is archived on Zenodo, where each release has its own DOI
(`doi:10.5281/zenodo.7566489 <https://doi.org/10.5281/zenodo.7566489>`_).

The self-consistent Fermi-level algorithm follows the original FORTRAN SC-Fermi
code (`Buckeridge 2019 <https://doi.org/10.1016/j.cpc.2019.06.017>`_).

For published work that uses py-sc-fermi, see the `citing articles on Google
Scholar <https://scholar.google.com/scholar?oi=bibs&hl=en&cites=12818294045062096499>`_.
